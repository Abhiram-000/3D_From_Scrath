# apps/web/src/lib/core/

## Responsibility

The app's model layer, deliberately UI-framework-free: the single owner of every network fetch and of the sessionStorage handoffs between pages, the honest loading-progress model, persisted settings, and small pure utilities for pointer coalescing, render pausing and the bounded chat context.

## Design

- `api.ts` — errors as values, never thrown. `generateStream(GenerateOptions)` returns `GenerateOutcome`; stall policy is arithmetic imported from contracts (`STALL_TIMEOUT_MS = STALL_HEARTBEATS(4) × HEARTBEAT_INTERVAL_MS(10_000)`, `TOTAL_TIMEOUT_MS = 6 × 60_000`), measured from the last _event_ (heartbeats count) rather than a wall clock; a stream that ends without a `ready`/`error` terminal event is itself a failure. `AbortError` is disambiguated into `aborted` vs `stalled` by whether the caller's own `signal` fired. `BUNDLE_KEY = 'edu3d.bundle.v2'`: one JSON document (`StoredBundle {code, manifest, raw}`) under one key, consumed once (`takeBundle` discards corrupt entries), peeked by the code/share panels (`peekBundleCode`, `storedRuntime` extracts the server's instrumented `runtime` twin from `raw`). `DEFAULT_COMPLEXITY = 'detailed'`.
- `loading-progress.ts` — `PHASES: PhaseSpec[]` gives each server `GenerationPhase` a contiguous 0–100 slice with a stage chip and local fallback `status`; `phaseOf` maps events; `ProgressModel.apply` is monotonic (a refinement re-running an earlier phase moves nothing back), `tick` eases `1 − e^(−t/τ)` toward but never past `to`; the on-screen sentence is the server's (`event.message`), the local one only a fallback. `view()` returns a plain object because a class instance is not reactive in Svelte — the page copies it into `$state`. `FactQueue` shuffles a topic-categorised pool (Fisher–Yates) with no repeats per cycle.
- `settings.ts` — zod-validated `UserSettings` from `@edu3d/contracts`; `loadSettings` returns contract defaults on missing/corrupt/throwing storage; `SettingsStore.update` applies patches through `safeParse` and refuses any patch that fails the schema, changing nothing; `StorageLike` is structural so tests pass a plain object.
- `pointer.ts` — pure: `toCanvasPoint` (relative to a rect cached at gesture start, so no per-move `getBoundingClientRect`) and `shouldSendPointerNow` (`down`/`up` immediate, `move` coalesced — the worker raycasts once per frame).
- `render-pause.ts` — `anyOverlayOpen` + `shouldPauseRender(overlayOpen, paused)`; deliberately non-latching: read on every call so a modal-closed model resumes unless the learner had paused it themselves.
- `model-context.ts:toContext` — mirrors the server's extraction client-side: ≤40 named parts (with `partsOmitted`), ≤24 parameters, objectives ≤8, description clipped to 1200, plus optional `selectedPartId`.

## Flow

A topic becomes a stream like this: `routes/+page.svelte` gates the topic with `validate-topic.ts:suspiciousContent`, then `api.ts:storeTopic`/`storeComplexity` and navigates to `/loading`. There `routes/loading/+page.svelte` reads back `takeTopic`/`takeComplexity` and calls `api.ts:generateStream` with `tier: detectTier().tier` (from `lib/engine/sandbox-host.ts`) and an `onEvent` callback; every NDJSON event goes to `loading-progress.ts:ProgressModel.apply`, the page ticks `tick()` per rAF and copies `view()` into Svelte `$state` (chips from `completedStages`, bar from `value`, wording from `status`). On the `ready` event `storeBundle({code, manifest, raw})` hands off and the route pushes to `/viewer`. The viewer `api.ts:takeBundle()`s it, loads `api.ts:storedRuntime(bundle)` into the sandbox host, and the conversational modes build requests with `model-context.ts:toContext(manifest, selectedPartId)`. Overlay/pause state flows through `render-pause.ts:shouldPauseRender` into `host.setPaused`.

## Integration

Depends on `@edu3d/contracts` (`GenerationEvent`, `ModelBundle`, `ComplexityPreference`, `COMPLEXITY_IDS`, `GENERATION_PHASES`, `STALL_HEARTBEATS`, `HEARTBEAT_INTERVAL_MS`, `SETTINGS_STORAGE_KEY`, `UserSettings`, `ModelContext`, `ModelManifest`) and on `lib/engine` only for `detectTier` (used by callers, not by this folder itself). Boundaries: `POST /api/generate` (streaming), plus non-streaming calls via `apiFetch` — `POST /api/gallery` + `GET /api/gallery/:id` (`components/share-modal.svelte`, `components/gallery-modal.svelte`), `POST /api/chat` (`components/chat-panel-v1.svelte`), `POST /api/quiz` (`routes/viewer/+page.svelte`). Consumers: the three route pages, `components/generate-dialog.svelte` (`generateStream` + `ProgressModel`), `components/code-view-modal.svelte` (`peekBundleCode`). Tests pin each contract: `loading-progress.test.ts` (monotonicity, unknown-phase milestone, `view()` plainness), `settings.test.ts` (corrupt/throwing storage, refused patch), `pointer.test.ts`, `render-pause.test.ts` (no latching).

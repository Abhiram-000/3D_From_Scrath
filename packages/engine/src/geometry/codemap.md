# geometry/

## Responsibility

The layer that turns every shape the AI can express — a user-facing builder call, a raw typed-array mesh, a closure function (SDF/parametric/height field), or a 2D profile — into plain triangle data (`MeshData`), and provides the cash-and-carry operations on that data: modifiers, pattern placements, and the decimation cut. There is no shape catalog; `MeshData` makes the set of expressible shapes the set of triangles (`00-GOAL.md` "the ceiling is the API, not the schema").

## Design

- **Data currency** — `mesh-data.ts:MeshData`: flat typed arrays (`positions: Float32Array` xyz, optional `indices/normals/uvs/colors`, plus `groups: {name,start,count}` named vertex ranges). Derived counts only: `vertexCount`, `triangleCount`. `Profile` (xy `Float32Array`, `closed`, optional `holes: Float32Array[]`) and `Path3` (xyz `Float32Array`, `closed`, optional `ups`) are the inputs to every solid operator and deliberately cheaper than CSG for holes.
- **Factory + opaque handles** — `factory.ts:GeometryFactory` is the _only_ place geometry enters the system (`register`): validates numerics (`requireFinite`, `clampSegments`, `requireVec3`), dedups by `structuralKey` (JSON on sorted keys, numbers rounded to 1e-6; typed arrays keyed by length+sampled digest; closures identified by `nextClosureId` WeakMap counter), enforces the per-build `SANDBOX_LIMITS.maxTotalVertices` ceiling, computes missing normals via `computeNormals`, and emits frozen `GeometryHandle`s (`__brand`, builder, cacheKey, vertices, triangles, boundingRadius, modifiers chain). The key is **bounded to the wire contract's 512 chars** — when the structural form would exceed it, the key becomes `builder:#h<length>x<128-bit digest>` (pure-JS, because the DOM-free worker recomputes these keys when it realizes a Node-authored manifest, so `node:crypto` is unavailable): exact dedup is kept while a published manifest cannot carry an unbounded key (the reference turbofan's raw key is 3,114 chars, which made the platform unable to publish its own exemplar). Guest never touches buffers; `resolve()` is host-only.
- **Composition over MeshData** — every builder and modifier is `MeshData → MeshData` (`modifiers.ts` header); nothing mutates its input because a cached mesh is shared. `applyModifier` records the chain on the handle (`modifiers: ['revolve','subdivide','twist']`).
- **Pure geometry** — all builders/solid operators run in Node with zero deps beyond three's math: the marching-cubes `EDGE_TABLE`/`TRI_TABLE` are reproduced inline as data (`implicit.ts` header); ear clipping + hole bridging is in-house (`triangulate.ts:earClip`, `bridgeHole`) with a guard against self-intersecting outlines spinning.
- **The solid algebra** — `profiles.ts` (profile, rect, circle/ellipse/polygon/arc, chained cubic `bezier`, Catmull–Rom `spline`, NACA 4-digit `airfoil`, true `gearProfile` involute, `offsetProfile` angle-bisector with miter scale, `filletProfile` quadratic-Bézier corners, `withHoles`, transforms, `signedArea`/`ensureCcw`) + `solids.ts` (`stitchRings` ring-stitching primitive; `addCap` via `triangulateProfile` with flipped far cap; `revolve`, `extrude` with taper/twist, `sweep` over `pathFrames` parallel-transport frames, `loft` via arc-length `resampleProfile`, `pipe` annular cross-section, `patch`). `primitives.ts` is sugar: most delegate to these (cylinder = 3 revolves merged, box = 6 hard-edged faces, dodecahedron = derived as the icosahedron's dual with per-face outward-flip).
- **Two reductions, no throw** — `modifiers.ts:simplify` is vertex clustering (O(n), never fails); `decimate.ts:decimate` is QEM edge collapse (Garland–Heckbert): flat `Float64Array` quadric accumulator (10 slots/vertex), lazy double-based heap of parallel arrays with (cost, a, b) total order, per-edge boundary floor (`BOUNDARY_ABSOLUTE_FLOOR = 1e8`, absolute not multiplicative because a planar rim prices at 0), version-stamped entries to skip stale collapses, whole function wrapped in try/catch returning the input unchanged (fail-soft is the contract).
- **Patterns return placements, not meshes** — `patterns.ts:Placement` (`{position, rotation?, scale?, label?}`) feeds instancing; `linear/radial/grid/alongPath` (arc-length param.)/`spiral` (golden angle)/`onSphere` (Fibonacci)/`helical/scatter` (bounded rejection sampling) + `mirrorPlacements/offsetPlacements`.
- Tricky numerics: normals are area-weighted (un-normalised cross product is the weight, `mesh-data.ts:computeNormals`); zero-length normals point up; NaN positions skipped in `meshBounds`, clamped in `sanitizeMesh`; `meshToField` (factory) approximates a mesh as an SDF (nearest vertex, sign from normal dot) for boolean via re-meshing — approximate by design, documented.

## Flow

1. Guest build code calls the frozen `geom` facade returned by `factory.ts:createFacade()` — e.g. `geom.extrude({profile: geom.airfoilProfile(...)...})`.
2. Each argument is validated (finite numbers, ≥3-point profiles, radii > 0, pipe inner < outer); profile/path cores are called (`profiles.ts:*`, `factory.ts:splinePath` in-line Catmull–Rom) to build `Profile`/`Path3`, kept behind `ProfileHandle`/`PathHandle` in WeakMaps.
3. `GeometryFactory.register(builder, spec, build)` keys the call, runs the builder (primitives → solids → triangulate/implicit `sdf` marching cubes → `parametric` grid), prices the mesh, applies `applyModifier` chains (`modifiers.ts` weld/subdivide/displace/clip/...), and returns a `GeometryHandle`; identical specs get the same handle (hit/miss counters in `stats`, per-builder ms in `buildTimings()`).
4. Host-side (`runtime/realize.ts`) resolves caches: `factory.resolve(handle) → MeshData`, snapped by `cacheKey`, decimated via `decimate` per the quality ladder.
5. Output: one `MeshData` per distinct key (uploaded once), one `GeometryHandle` per part in the authoring scene.

## Integration

- Depends on: `../math/index.ts` (`TAU`, `clamp`, `lerp`, `fbm`, `smootherstep`, `normalize`, `cross`, `GOLDEN_ANGLE`, `Vec3`) and `@edu3d/contracts` (`SANDBOX_LIMITS.maxTotalVertices`).
- Consumed by: `authoring/api-surface.ts:buildApiSurface` (`collect('geom', geometry.createFacade())` — the surface the static gate validates and the prompt is generated from); `authoring/scene.ts` (`GeometryHandle`, `PathHandle`, `Placement`); `runtime/realize.ts` (`decimate`, the `MeshData` type, and `node.geometry.cacheKey` keys produced by the authoring pass); `hosts/node-host.ts` and `authoring/guest.ts` (`GeometryError` for error gates); `index.ts` re-exports everything (`primitives`, `solids`, `implicit`, `modifiers`, `profiles`, `patterns`, `triangulateProfile`, `decimate`, `GeometryFactory`).
- Behavioural contract pinned by `tests/geometry.test.ts` (expressive ceiling, winding, gear tooth count, cache dedup, booleans) and `tests/decimate.test.ts` (clean + adversarial populations: no throw and unchanged output on non-manifold/NaN/duplicated input, determinism, asymmetric-mesh silhouette survival).

# apps/web/src/routes/viewer/

## Responsibility

The viewer: the full app shell hosting the sandboxed engine (`SandboxHost` + Web Worker), toolbar/left/right panels/bottom bar, all modal state, the model-load priority chain, learner notes and export, and the atomic swap every model entry point funnels through.

## Design

- Single `+page.svelte` owning all shell state as `$state` (`leftOpen`/`rightOpen`/`activeTab`/`activeMode`/`viewMode`, the eight modal flags, `theme`, `topicName`, `deviceTier`, toast list). Engine events arrive through `callbacks: HostCallbacks` and write into it (`onLoaded` adopts the manifest, resets parameter defaults, rebuilds the per-model `AnnotationStore`, and calls `unloadModes()` so a model swap unloads the previous model's story/quiz; `onKilled` nulls `manifest`/`stats` and toasts).
- `manifest`, `verdict`, `stats`, `metrics`, `parameterValues`, `notes`, `projectedAnnotations`, `modelLabels`, `projectedLabels`, `recordingCapability` are deliberate `$state.raw`: every write reassigns a fresh value (parameter writes spread), never mutates — so deep proxies would only charge a `get` trap per property read across hundreds of parts on every hover and inside `code-view-modal`'s `JSON.stringify`. Classes like `ProgressModel` must stay deep-`$state` (their instances mutate in place; `.raw` would silently freeze them).
- The toolbar's model-name lockup carries the early-beta marker: a `.beta-chip` span after `.topic-name` with `title` plus an `.sr-only` expansion for assistive tech. It is deliberately inert — no `onclick`, no `tabindex`, no role — so it can never fire the global `keydown` shortcut handler. `.topic-name` is the lockup's one shrinkable child (`min-width:0; overflow:hidden; text-overflow:ellipsis`) and the chip is `flex:none`, so a long generated name ellipsises and the chip keeps its size rather than being pushed off the row.
- `currentProgram` (`{code, runtime?} | null`) is this page's single answer to "what program is on screen": the loading handoff is consumed once here, and every later load (share link, gallery, Generate swap) replaces it along with the model, so the share modal and code panel can never disagree with the manifest beside them (the old design peeked the consumed storage key, which after one load was empty — the share modal then published the reference source under the generated model's manifest). `null` means the built-in reference model and is labelled as such.
- `lib/core/settings.ts:SettingsStore` (plain class, not rendered) holds the persisted choices; `pinnedQuality` mirrors the quality pin into `$state` at mount and `setPinnedQuality()` rewrites it via `settings.update({ quality })` + `host.setQuality(...)`, toasting honestly ("Auto" unpins; a pin warns instead of silently adapting). Until the Settings dialog existed no control called this, so the choice the contract promised was unreachable.
- Deriveds build lookup Maps once per manifest — `partsById`/`metricsById` (replacing per-hover linear `.find()` over the proxy) — plus `activePart` (`selectedPart ?? hoveredPart`), `listedParts` (first 200 selectable non-group parts), `selectedPartInfo`, and `overviewHtmlSafe` (only text-safe manifest fields: name, description, pedagogy). The right panel's selected/overview branch is gated by `$lib/components/panel-branch.ts`: `{#if selectedPartInfo && panelShowsSelectedPart(selectedPart, selectedPartInfo)}`. The parts list is hoisted _outside_ that branch: every arm used to replace the whole panel, so selecting one part deleted the list that selecting another part needs and left a mouse-free learner stuck on the first part the canvas registered.
- Side panels carry both `class:collapsed={!open}` and `class:active={open}`. Below 768px the sheets sit at `translateX(±100%)` and the shipped CSS restores them on `.active`; toggling only `.collapsed` left Parameters, Chat and Information unreachable on a phone (the phone E2E asserted only canvas width, so it passed while the surface was gone).
- One `$effect` owns render pausing: it reads every modal flag + `paused` through `anyOverlayOpen()` / `shouldPauseRender()` before calling `host.setPaused()` — reading both before acting is what makes it impossible to latch (a pause for one modal must not leak into the next model; a user-paused model stays paused).
- Honest status bar: `qualityLabel`/`qualityTitle` report the worker's _effective_ preset (`stats.quality`) and mark it adapted only when the ladder actually stepped down (`stats.degradedRungs`), not whenever the load-time verdict carried an adjustment; the `cacheHitRate` is shown as measured; and the Physics line is three distinguishable states (`Off` when the manifest declares no simulation, the solver's per-frame ms when `stats.physicsActive`, and `Unavailable` with `stats.physicsUnavailableReason` when a declared solver is not stepping) — it used to read "On" from `manifest.physics` alone, a fake trust indicator (`03` R9).
- Pointer path: `canvasRect` cached via `ResizeObserver`; `dispatchPointer` sends `down`/`up` immediately and coalesces `move` to one requestAnimationFrame sample (`shouldSendPointerNow`, `toCanvasPoint`, `flushHover`); `onpointercancel` is bound alongside `pointerup` so a lost capture cannot strand the `dragging` flag.

## Flow

- Mount: `sandboxSupported()` gate → `Ambient` with grid/spotlight/blobs all disabled (over an opaque WebGL canvas) → `new SandboxHost(canvasHolder, callbacks, { quality: pinnedQuality })` → `start()` → `host.setTheme(readThemeColors())` → load by priority (`03` R2): `?model=<id>` → `loadFromGallery` (GET `/gallery/:id`; failure toasts and falls back to `REFERENCE_MODEL_SOURCE`), else the stored session bundle (`takeBundle()` → `host.load(code, 7, storedRuntime(bundle))` — the instrumented `runtime` twin gives the model its browser-side loop guard), else `host.load(REFERENCE_MODEL_SOURCE, 7)`. A frozen `window.__edu3dHost` diagnostic handle is installed and deleted in `onDestroy` (before `host.dispose()`).
- Keyboard handler (inert while typing in `input/textarea/select`): space toggles pause, `r` → `resetModel`, `1–6`/`v` → `host.viewPreset`, `x/w/e` → `setViewMode`, `f` fullscreen, `s` story, `q` quiz, `g` → AI Output, `n` generate, `l` gallery, `p` share, `c` HD screenshot, `a` note placement mode, `[`/`]` toggle the left/right panels, `t` theme, `,` settings, `?` shortcuts, `ctrl+z/y` undo/redo. Escape closes any open modal, then exits `activeMode`, then leaves note-placement mode, then clears selection + normal view.
- Mode entry: `enterStory` requires `manifest.story.length`; `enterQuiz` prefers authored `manifest.quiz` (`quizSource: 'authored'`) else POSTs `/quiz` with `toContext(manifest, selectedPart)`, count 5, mixed difficulty (`quizSource: 'generated'`) and toasts when unavailable.
- Reset (`resetModel`): the authored initial state, not just a clock — re-applies every parameter default through `applySnapshot`, drops the undo/redo history and the open gesture (a reset is not an edit to walk back from), then `host.resetTime()` + `host.resetCamera()`. Previously it only reset the clock, leaving a dragged-slider model permanently off its authored pose; live verification caught the turbofan's spool still at 12 000 rpm.
- Notes (`03` R7): `AnnotationStore` is rebuilt per model on load; `toggleNotePlacing` arms placement, a canvas click resolves to a world point via `host.pickPoint` (raycast in the worker), and the draft pin is shown but not stored until words exist; `syncNotes` is the one place the pin set reaches the worker (`host.setAnnotations`) and the `AnnotationLayer` prop; `placeNote`/`saveNote`/`deleteNote` cover the three edits. Storage refusal is surfaced once ("session-only") rather than promised.
- Model labels (`01`: parts self-describing): `onLoaded` adopts `manifest.labels` into `modelLabels` and clears `projectedLabels`; `onLabelPositions` stores the worker's `ProjectedLabel[]`; the read-only `ModelLabels` overlay is mounted in the canvas holder beneath the annotation layer. `onKilled` clears both so a previous model's words cannot linger over a new one.
- Export (`03` R8): `ExportMenu` is fed `recordingCapability`/`recording`/`recordingSeconds`; screenshots go through `requestSnapshot(preset)` and land on `onSnapshot` (the `captureSnapshot` wrapper hands the bytes to the share modal's thumbnail instead of downloading when one is pending); recording maps to `startRecording`/`stopRecording` with results on `onVideoClip`/`onRecordingFailed`.
- Story mode wiring: callbacks are stable named functions (`beatSetParameter`, `focusStoryPart`, `playStoryShot`, `closeStory`), not inline arrows, so the story subtree is not re-created per frame and the beat effect cannot re-trigger itself — the other half of the `untrack` fix inside `story-mode.svelte`; without both, a beat's parameter write re-rendered the page, which handed down fresh callbacks and re-ran the effect (`effect_update_depth_exceeded`, a frozen viewer).
- Atomic model swap: `swapInModel(code, name, runtime)` (gallery's `onload` / generate-dialog's `ongenerated`) sets `modelLoading`, updates `currentProgram`, closes both dialogs and calls `host.load(...)` with a random seed — a failed load leaves the previous model on screen (`03` R2).
- Parameter gestures: `onParameterInput` → `noteParameterGesture()` (600ms batch window) → snapshot into `undoStack`/`redoStack` (one 50-entry cap via `pushCapped`) → `host.setParameter`; undo/redo reapply snapshots through the host. Selection also narrates the part's description through `narratePart`, gated on the `narration` setting and remembering the last announced id.
- Teardown: `cancelPendingHover()`, clear toast/gesture timers, delete `__edu3dHost`, `host.dispose()`.

## Integration

- `$lib/engine/sandbox-host.ts` (`SandboxHost`, `sandboxSupported`, `SNAPSHOT_PRESETS`, `SnapshotPreset`), `$lib/engine/sandbox-worker.ts` (`SerializableVerdict`); `$lib/core/api.ts` (`apiFetch`, `takeBundle`, `storedRuntime`), `$lib/core/settings.ts` (`SettingsStore`, `narratePart`), `$lib/core/render-pause.ts` (`anyOverlayOpen`, `shouldPauseRender`), `$lib/core/pointer.ts`, `$lib/core/model-context.ts:toContext`, `$lib/annotations/annotations.ts` (`AnnotationStore`, `annotationId`, `toAnnotationPins`); `$lib/ambient.ts` (`getTheme`, `setTheme`); the ten `$lib/components/*` (including `settings-modal.svelte`, `annotation-layer.svelte`, `model-labels.svelte`, `export-menu.svelte`); `@edu3d/engine:REFERENCE_MODEL_SOURCE`; contracts `ModelManifest`, `ModelLabel`, `QualityPreset`, `QuizQuestion`, `RuntimeStats`, `Annotation`, `ProjectedAnnotation`, `ProjectedLabel`, `ShotDecl`, `VideoRecordingCapability`.
- Endpoints: `GET /gallery/:id` (shared-link entry), `POST /quiz` (generated questions). Styles: `viewer.css` + `viewer-extended.css`; scene colors come from the token sheets via `readThemeColors()` (`--scene-bg-top/bottom`).

# packages/engine/src/authoring/

## Responsibility

The authoring layer: runs the AI's guest program exactly once against the `scene`/`geom`/`mat` facades to emit a serialisable, GPU-free `ModelManifest` plus a live `SceneBuilder` of callbacks, and owns the documentation of the call surface the gate and generation prompt are built from.

## Design

- `scene.ts:SceneBuilder` — the accumulator: parts map + insertion `order` + `parentStack`, parameters (cap 24, `param()`), metrics, motions, paths, interactions, lights, shots, story, quiz, reusable `components` map. Owns its `GeometryFactory`/`MaterialFactory`; `dispose()` releases caches, cached `PartRef`s and the frame context. Validation helpers (`requireId` with `ID_PATTERN`, `requireText`, `vec3`, `addPart`, `resolveParent`) throw `SceneError` whose messages address the generator; over-limit inputs degrade to recorded `warnings`. All ids, counts (`MAX_PARTS`, `MAX_INSTANCES_PER_SET`) and physics are enforced here, at the boundary — **structurally, not through zod**: this file runs inside the poisoned guest realm where `Function` is a thrower, so any `.parse`/`.safeParse` would throw `Function is not available inside the model sandbox` (a browser-only failure `node:vm` never sees). Closed vocabularies still come from the contract — an enum's `.options`/`.shape` is read at module scope (a property read, safe) and every membership test names the legal values.
- `scene.ts:SceneBuilder.createFacade()` — the frozen `scene` facade (describe → colorRole → structure → param/metric/motion/path/light/camera/shot/environment/story/quiz/interaction/physics/warn + `onFrame` (≤16)/`onParameterChange`/`onSelect`/`onInteraction`); `motion()` refuses the `follow`/`sequence` kinds a `MotionDecl` cannot express. `defineComponent`/`place` body via `createComponentContext` (id-prefixed, parent-wired). Per-frame machinery: reusable `FrameContext` (`createFrameContext`, `params` is a live Proxy, zero per-frame allocations), cached `PartRef`s (`makePartRef` — setters quarantine non-finite values and `noteWrite` per channel), `publishProbes`, `runFrame`, `setParameter`, `motorTargets`; dry-run sweep support (`sweepParameter`/`endParameterSweep`/`sweepBaseline` restore/`sweepStateSignature` quantised at 3 decimals, `observedWrites`, `sweepStates`, `touchedParts`). `toManifest()` refuses a build with no `describe` or no parts, prices `computeCost` from declared geometry (instances = N×triangles, 1 draw call) and falls back to `deriveCamera` (2.4× radius, 25°) only when `camera()` was not called.
- `guest.ts:authorModel(options): AuthorResult` — the sandbox join; ordering is the security design: `createGuard()` + `compileGuest(code)` while the host still holds `new Function` → bindings (`scene`/`geom`/`mat` facades, `Object.freeze`d `M`, seeded `random`, capped `console` via `createConsole`) → `hardenRealm(scope)` → `compiled.run(bindings)` → `builder.toManifest()`. Never throws: `describeFailure` turns `SceneError`/`GeometryError`/`MaterialError`, `GuestTimeoutError`/`GuestBudgetError`, stack overflow and thrown non-Errors into actionable `AuthorFailure { message, timedOut }`. `runFrame(builder, guard, …)` resets the guard to `SANDBOX_LIMITS.frameDeadlineMs` — build budget and frame budget are separate.
- `api-surface.ts` — the reflective descriptor: `buildApiSurface()` instantiates real factories and walks their facades (`collect()`, one nesting level, functions **and** constants like `M.TAU`) plus host-provided `console`/`random`; memoised `apiSurface()`; `apiSurfaceSet()` is the static gate's accept set; `describeApiSurface()` renders deterministic (sorted, non-`localeCompare`) prompt docs.
- `api-reference.ts:API_REFERENCE` — pure-data hand-written table of `ApiReferenceEntry {signature, summary, example}` for every surface member ("how to call it"), import-free (its only imports are the contract enums it renders) so the server can put it in prompts. **Every enum union in a signature is rendered from the contract's frozen zod enums** (shot kind/easing, interaction kind, light kind, body/joint kind, story view mode) rather than retyped by hand — a hand-maintained union once taught the generator a value the schema rejects, so a model could pass the prompt and fail the gate. Welded to the reflective surface in both directions by `tests/api-reference.test.ts`.

## Flow

Guest source (already gate-checked + loop-instrumented) → `authorModel` → facade calls mutate the builder → `compiled.run` → `toManifest()` → `{ manifest, builder, logs, durationMs }`. The retained builder is then driven for frames (`runFrame`), parameter changes (`setParameter`) and audit sweeps (`sweepParameter`). Deviations return `AuthorFailure` for the repair pass. `index.ts` is the `./authoring` subpath barrel re-exporting all four modules.

## Integration

Depends on `@edu3d/contracts` (manifest decls, `MAX_PARTS`, `PhysicsDeclSchema`), `@edu3d/sandbox` (`compileGuest`, `createGuard`, `hardenRealm`, `GuestTimeoutError`, `GuestBudgetError`), and sibling `geometry/`, `materials/`, `math/`. Consumed by `packages/sandbox`'s gate (through `apiSurfaceSet`), `apps/server/src/services/prompts.ts` (`describeApiSurface` + `REFERENCE_MODEL_SOURCE` few-shot), `apps/web/src/lib/engine/sandbox-worker.ts` (`SceneBuilder`, `SceneError`, `M`, error classes; `authorModel` in web engine tests), and `apps/server/src/services/audit.ts` via the Node host. Evidence: `tests/authoring.test.ts`, `tests/api-reference.test.ts`.

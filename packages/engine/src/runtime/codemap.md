# packages/engine/src/runtime/

## Responsibility

The manifest-consumption half of the engine: price a manifest against a device tier before anything is allocated (`admission.ts`), realize it into a Three.js scene graph on the learner's device only (`realize.ts`), and apply declared motions to live transforms every tick (`motions.ts`). Pricing runs anywhere (server included); realization never runs on the server.

## Design

- `admission.ts` — pure manifest arithmetic, no GPU. `priceModel(manifest, tier): AdmissionVerdict` walks `QUALITY_LADDER` least damage first: post-processing allowance, shadows (brightest lights claim `budget.maxShadowLights`), particles (point clouds scaled proportionally, floor 64; instance sets thinned non-hero-first/largest-first with placement floors `RECOGNIZABILITY_FLOOR = 0.25` / `HERO_FLOOR = 0.55`, min count 3), geometry decimation (`decimationOrder`: non-hero before hero, largest first, skip <64 triangles; honest `refusal` naming real numbers when even the floors don't fit), draw-call relief priced via `staticGeometry` merging (the realizer merges; not a ladder rung), `flatShading` forced on `low` only, physics substep/body trims. Invariant: never removes a part — "the same lesson, coarser". Emits learner-facing `AdmissionAdjustment {rung, message, saved}` and per-part `RealizationDecisions {decimation, shadowLights, pointCaps, instanceCaps, postProcessing, maxPixelRatio, maxSubsteps, flatShading}`. `remainingRungs(applied)` shares the ladder order with the live adaptive ladder; `summarizeCost` is the status-bar line.
- `motions.ts` — stateless consumer of `manifest.motions` with two rules: every pose is **absolute** (authored base + `elapsed`; never `+=`), so reset/time-scrub are exact; and **zero NaN** (`finiteOrZero` quarantine; `resolveScalar` defaults missing `param`/`probe`/`scale`/`offset` to safe values via `in` guards, because the builder captures `ScalarSourceInput` verbatim, never zod-round-tripped). `MotionHost` is the host contract: immutable `baseTransform`, host-reset `liveTransform` (worker reset→model code→`applyMotions` ordering makes composition with `onFrame` deterministic), optional `pointOnPath`. Kinds: `spin` (right-composed quaternion, axis part-local), `oscillate` (Hz, metres), `orbit` (Rodrigues on the radius vector, tidal-locked left-composed rotation), `translate` (m/s), `pulse` (scale factor ≥ `PULSE_MIN_FACTOR`, holds unity on a non-finite wave), `flowAlongPath` (wrapped fraction); `follow`/`sequence` are skipped (unexpressible in `MotionDeclInput`). Deliberately import-free beyond `@edu3d/contracts` types (`MotionDeclInput`, `ScalarSourceInput`) and allocation-free per frame (module scratch triples/quartets, `setVec3` in-place writes, gimbal-lock-safe `eulerFromQuatInto`).
- `realize.ts` — the one module touching Three.js/GPU. `realize({manifest, geometries, decisions}): RealizedModel` builds into a detached `THREE.Group` for atomic swap (`03` R2). Structural caches keyed by `cacheKey` (`@decimateTo` and `#flat` suffixes so decimation/flat shading don't poison identical full-detail parts); `toBufferGeometry` runs QEM `decimate` and substitutes a valid `Sphere` for a NaN-poisoned bounding sphere; `toMaterial` maps archetypes to concrete Three materials (`wire`→MeshBasicMaterial, `toon`→MeshToonMaterial, `emissive`→MeshStandardMaterial, `glass`/`fluid`/`translucent`→MeshPhysicalMaterial with transmission, `organic`→sheen, `metal`→MeshStandardMaterial), `toColor` does the single sRGB→linear conversion. One parent-first pass attaches group/mesh/instances/points nodes; shadows granted only to `decisions.shadowLights`; the default key+fill rig is added only when no lights were declared; `stats.triangles`/`drawCalls` are realized counts (post-decimation, `count`-multiplied for instanced sets), not the authored totals; `dispose()` releases caches, discovered textures, shadow maps.

## Flow

Guest build (authoring) → `ModelManifest` + geometry `Map<cacheKey, MeshData>` → `priceModel` returns `AdmissionVerdict` (admit/refuse) → on the device, `realize` builds `RealizedModel.root` which the worker swaps onto the live scene → every frame: host reset live→base, `runFrame` (authoring), `applyMotions(host, {params, elapsed}, paused)` → renderer reads the mutated live transforms.

## Integration

Depends on `@edu3d/contracts` (`DEVICE_BUDGETS`, `QUALITY_LADDER`, manifest types) and, from inside the package, `geometry/decimate.ts` + `geometry/mesh-data.ts`. Consumed by `apps/web/src/lib/engine/sandbox-worker.ts` (`priceModel`, `realize`, `applyMotions`, types `PartTransformLike`/`MotionHost`/`ScalarContext`/`RealizedModel`/`AdmissionVerdict`), `apps/web/src/lib/engine/frame-compose.ts` (`PartTransformLike`), the server audit's budget dimension (via Node host), and `tests/host-admission.test.ts`, `tests/realize-decimate.test.ts`, `tests/motions.test.ts`, `tests/frame-cost.test.ts`.
